# MaxQHide — Win11 老板键

一个用 Python 编写的 Windows 11 老板键工具。按一个组合键，立即把配置好的游戏（或任意程序）窗口全部隐藏：**程序继续在后台正常运行，但任务栏不显示任何图标**；再按一个组合键即可全部唤醒。

纯标准库实现（ctypes + tkinter），**无需 pip 安装任何依赖**。

## 运行

- 要求：Windows 10/11 + Python 3.8 及以上
- 双击 `bosskey.pyw`，或命令行运行：

```
pythonw bosskey.pyw
```

首次运行会自动生成 `config.json`，并在系统托盘出现一个"眼睛"图标。

## 使用说明

| 操作 | 说明 |
| --- | --- |
| `Ctrl+Alt+H` | 一键隐藏列表中所有程序（默认热键） |
| `Ctrl+Alt+S` | 一键唤醒全部被隐藏的程序（默认热键） |
| 程序独立热键 | 可为每个程序单独设置热键，按下后只隐藏/唤醒该程序（再按一次切换） |
| 双击托盘图标 | 打开设置窗口 |
| 托盘右键 | 打开设置 / 立即隐藏 / 立即唤醒 / 退出 |

- 托盘图标会随状态变化：睁眼=正常，闭眼=当前有窗口处于隐藏状态，悬停可看到隐藏数量。
- 隐藏期间游戏弹出的新窗口（加载框、报错框等）会被自动隐藏。
- 设置窗口本身也可以随老板键一起隐藏（默认开启，可在界面中关闭）。
- 关闭设置窗口 = 最小化到托盘继续运行；**退出程序请用托盘右键菜单的"退出"**。

## 添加要隐藏的程序

打开设置窗口，两种方式：

1. **从运行中的程序添加**：列出当前所有可见窗口，勾选即可（推荐）。
2. **手动添加**：填写规则，两种匹配方式：
   - `进程名`：如 `yuanshen.exe`（不写 `.exe` 也行），精确匹配进程；
   - `标题包含`：窗口标题包含该关键字即匹配，适合 UWP / Xbox 商店游戏（这类游戏统一跑在 `ApplicationFrameHost.exe` 里，无法按进程名区分）。

每条规则还可设置**独立热键**：双击列表中的规则（或点"编辑"），点击"独立热键"按钮按下组合键即可。按下独立热键只作用于该程序——有可见窗口就隐藏，已隐藏则唤醒，再按一次切换。热键不可与全局热键或其他程序的热键重复，重复时保存会提示并清除。

所有规则保存在 `config.json`，可直接手工编辑，保存后重启程序生效：

```json
{
  "hide_hotkey": "ctrl+alt+h",
  "show_hotkey": "ctrl+alt+s",
  "hide_gui": true,
  "monitor_new_windows": true,
  "autostart": false,
  "programs": [
    {"id": 1, "name": "示例：记事本", "match_type": "process", "match_value": "notepad.exe", "enabled": true},
    {"id": 2, "name": "某UWP游戏", "match_type": "title", "match_value": "游戏窗口标题关键词", "enabled": true, "hotkey": "ctrl+f6"}
  ]
}
```

规则中可选的 `hotkey` 字段即该程序的独立热键（toggle 切换隐藏/唤醒），可省略。

热键写法：`ctrl` / `alt` / `shift` / `win` 任意组合 + 字母/数字/F1-F24/方向键等，**两键即可（如 `ctrl+h`）**，但至少要含一个修饰键，否则会拦截正常打字。

## 命令行模式

```
python bosskey.pyw --list    # 列出当前匹配的窗口及状态（可见/已隐藏）
python bosskey.pyw --hide    # 立即隐藏所有匹配窗口
python bosskey.pyw --show    # 唤醒所有匹配的隐藏窗口
```

命令行模式与托盘程序互相独立，即使主程序没在运行也可以使用。

## 常见问题

- **隐藏游戏没反应？** 若游戏以管理员身份运行，本工具也需要右键"以管理员身份运行"才能操作它的窗口（Windows 权限隔离限制）。
- **热键无效/注册失败？** 该组合键可能被其他软件（输入法、显卡驱动、聊天软件）占用，在设置里换一个即可，状态栏会提示注册结果。
- **捕获组合键的识别**：以物理按键状态为准（不受输入法合成事件干扰）；`Alt+字母` 在部分输入法下会被系统拦截而无法捕获，建议优先 `Ctrl`/`Shift` 组合。
- **全屏游戏**：隐藏时系统会把独占全屏游戏切回桌面，唤醒后恢复；个别反作弊游戏可能对窗口操作敏感，请自行确认。
- **开机自启**：设置窗口勾选即可（在 `shell:startup` 放置启动脚本）。移动本程序位置后请重新勾选一次。
- **本工具只操作本机窗口显示状态，不注入、不修改任何游戏进程。**
